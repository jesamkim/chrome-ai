API Key 발급 방법
  1. AWS 콘솔에 로그인합니다
  2. Bedrock 서비스로 이동합니다
  3. API Keys 메뉴에서 새 키를 생성합니다
  4. 생성된 키를 복사하여 위 입력란에 붙여넣습니다

주의: API Key는 안전하게 보관하고 타인과 공유하지 마세요.

사용 방법
  • 팝업 사용: 브라우저 툴바의 확장 프로그램 아이콘을 클릭
  • 컨텍스트 메뉴: 텍스트 선택 후 우클릭하여 분석
  • 자동 분석: 설정 활성화 시 페이지 로드 시 자동 분석
문제 해결
  • 연결 실패: API Key가 올바른지 확인하세요
  • 응답 없음: 네트워크 연결을 확인하세요
  • 느린 응답: 토큰 수를 줄여보세요
