Claude AI Chrome Extension

AWS Bedrock Claude 3.7 Sonnet 기반 웹페이지 분석 AI 어시스턴트

🚀 Extension 기능 소개

📄 지능형 웹페이지 분석

현재 보고 있는 웹페이지의 내용을 Claude AI가 자동으로 분석하여 핵심 정보를 추출합니다.

💬 실시간 AI 채팅

페이지 내용을 바탕으로 Claude와 자연스러운 대화를 나눌 수 있습니다. 궁금한 점을 언제든 물어보세요!

⚡ 빠른 작업 도구

요약, 핵심 포인트 추출, 번역 등 자주 사용하는 기능을 원클릭으로 실행할 수 있습니다.

🎯 다중 모델 지원

Claude 3.7 Sonnet, Claude 4 Sonnet, Amazon Nova Pro, Nova Lite 등 다양한 AI 모델을 선택할 수 있습니다.

📋 Extension 사용 방법

1단계: Chrome 브라우저에서 chrome://extensions/ 페이지로 이동
2단계: 우측 상단의 "개발자 모드" 활성화
3단계: "압축해제된 확장 프로그램을 로드합니다" 클릭
4단계: 이 프로젝트 폴더(/Workshop/chrome-ai) 선택
5단계: Extension 아이콘 클릭 후 설정 페이지에서 AWS Bedrock API Key 입력
6단계: 이 페이지에서 Extension 기능 테스트!

📝 테스트용 샘플 콘텐츠

AWS Bedrock 소개

Amazon Bedrock은 Amazon Web Services(AWS)에서 제공하는 완전관리형 서비스로, 고성능 기반 모델(Foundation Models, FM)을 API를 통해 사용할 수 있게 해줍니다.

주요 특징:
  • Anthropic의 Claude, Amazon의 Titan 등 다양한 AI 모델 지원
  • 서버리스 아키텍처로 인프라 관리 불필요
  • 기업급 보안 및 프라이버시 보장
  • 사용한 만큼만 지불하는 종량제 요금

지원 모델 목록

  • Claude 3.7 Sonnet: 균형잡힌 성능과 속도를 제공하는 기본 모델
  • Claude 4 Sonnet: 최신 고성능 모델로 복잡한 추론 작업에 최적화
  • Amazon Nova Pro: 멀티모달 기능을 지원하는 고성능 모델
  • Amazon Nova Lite: 빠르고 경제적인 경량 모델

사용 사례

이 Extension을 사용하여 현재 페이지의 내용을 분석하고, 다음과 같은 질문들을 Claude에게 물어보세요:

  • "이 페이지의 주요 내용을 요약해주세요"
  • "AWS Bedrock의 핵심 장점은 무엇인가요?"
  • "지원되는 AI 모델들의 차이점을 설명해주세요"
  • "이 서비스를 어떤 상황에서 사용하면 좋을까요?"
