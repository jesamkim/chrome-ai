# Vector Store 완전 가이드

## 개념 이해

### Vector Store란?
텍스트의 **의미**를 수치 벡터로 변환하여 저장하고, 의미적 유사성을 기반으로 검색할 수 있는 시스템입니다.

## 작동 원리

### 1. 임베딩 (Embedding) 과정
```
텍스트: "사과는 빨간 과일이다"
     ↓ (임베딩 모델)
벡터: [0.2, -0.1, 0.8, 0.3, -0.5, 0.9, ...]
     (1536차원 숫자 배열)
```

### 2. 의미적 유사성 계산
```
질문: "빨간 과일은 무엇인가?"
벡터: [0.3, -0.2, 0.7, 0.4, -0.4, 0.8, ...]

유사도 계산 (코사인 유사도):
질문 벡터 vs 저장된 벡터들
→ "사과는 빨간 과일이다" (유사도: 0.89) ← 높은 유사도!
→ "하늘은 파랗다" (유사도: 0.12) ← 낮은 유사도
```

## 전통적 검색 vs Vector Store 검색

### 전통적 키워드 검색
```
질문: "빨간 과일"
검색: 텍스트에서 "빨간"과 "과일" 단어 찾기
결과: 정확히 이 단어들이 있는 문장만 찾음

문제점:
- "사과는 빨갛다" ← "빨간"이 없어서 못 찾음
- "apple is red" ← 영어라서 못 찾음
- "토마토는 붉은 채소다" ← "과일"이 없어서 못 찾음
```

### Vector Store 의미 검색
```
질문: "빨간 과일"
검색: 의미적으로 유사한 벡터 찾기
결과: 의미가 비슷한 모든 문장 찾음

장점:
- "사과는 빨갛다" ← 의미가 같아서 찾음 ✅
- "apple is red" ← 의미가 같아서 찾음 ✅  
- "토마토는 붉은 채소다" ← 유사한 의미로 찾음 ✅
- "딸기는 달콤하다" ← 관련 있어서 찾음 ✅
```

## Chrome Extension에서의 활용

### 현재 방식 (키워드 기반)
```
사용자: "이 페이지에서 가격 정보가 어디 있나요?"
시스템: 전체 페이지 텍스트를 Claude에게 전송
Claude: 8000자 전체를 읽고 가격 관련 부분 찾기
```

### Vector Store 방식 (의미 기반)
```
사용자: "이 페이지에서 가격 정보가 어디 있나요?"
시스템: "가격 정보" → 벡터 변환
Vector Store: 의미적으로 유사한 청크들 검색
결과: ["상품 가격: $29.99", "할인가 $19.99", "배송비 $5.00"]
Claude: 관련 부분만 받아서 빠르고 정확한 답변
```

## 기술적 구현

### 1. 임베딩 모델
- **Amazon Titan Embeddings V2**: AWS Bedrock에서 제공
- **출력**: 1536차원 벡터
- **언어**: 한국어, 영어 등 다국어 지원

### 2. 벡터 저장소
```javascript
// Chrome Extension에서의 구현 예시
const vectorStore = {
  "chunk_001": {
    content: "사과는 빨간 과일이다",
    vector: [0.2, -0.1, 0.8, 0.3, -0.5, 0.9, ...], // 1536개 숫자
    metadata: {
      pageUrl: "https://example.com",
      chunkIndex: 1,
      timestamp: "2024-01-01T00:00:00Z"
    }
  },
  "chunk_002": {
    content: "바나나는 노란 과일이다",
    vector: [0.1, 0.2, 0.7, 0.4, -0.3, 0.8, ...],
    metadata: { ... }
  }
}
```

### 3. 유사도 검색
```javascript
function findSimilarChunks(queryVector, topK = 5) {
  const similarities = [];
  
  for (const [chunkId, chunk] of Object.entries(vectorStore)) {
    const similarity = cosineSimilarity(queryVector, chunk.vector);
    similarities.push({ chunkId, similarity, content: chunk.content });
  }
  
  // 유사도 높은 순으로 정렬하여 상위 K개 반환
  return similarities
    .sort((a, b) => b.similarity - a.similarity)
    .slice(0, topK);
}
```

## Chrome Extension에서의 장점

### 1. 토큰 절약
```
현재 방식: 전체 페이지 (8000자) → Claude API
Vector Store: 관련 청크만 (1000자) → Claude API
절약: 87.5% 토큰 절약!
```

### 2. 응답 속도 향상
```
현재: 전체 텍스트 분석 → 3-5초
Vector Store: 로컬 검색 + 관련 부분만 분석 → 1-2초
```

### 3. 정확도 향상
```
현재: 긴 텍스트에서 관련 부분을 Claude가 찾아야 함
Vector Store: 이미 관련 부분만 선별되어 Claude에게 전달
```

## 결론

Vector Store는 **의미 기반 검색**을 가능하게 하는 혁신적인 기술입니다:

✅ **정확성**: 키워드가 없어도 의미로 찾기
✅ **효율성**: 관련 부분만 선별하여 API 호출
✅ **속도**: 로컬 검색으로 빠른 응답
✅ **비용**: 토큰 사용량 대폭 절약
✅ **사용자 경험**: 더 정확하고 빠른 답변

Chrome Extension에 Vector Store를 도입하면, 사용자가 페이지의 어떤 내용에 대해 질문하더라도 정확하고 빠르게 답변할 수 있게 됩니다!
